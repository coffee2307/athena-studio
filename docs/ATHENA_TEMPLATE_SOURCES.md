# Athena interactive template library — sources

These repositories were downloaded to review their information architecture and responsive patterns. The Athena demos are rebuilt as original React pages; the upstream HTML, CSS, JavaScript, and bundled stock photos are not copied into the public demo routes.

The four added directions extend the same visual research: architecture, wellness, property, and education. The registry retains a reference link for each demo.

## Demo photography

The local demo images are downloaded from Unsplash and stored under `public/template-demos/<slug>/`. Unsplash allows free commercial and non-commercial use under its current license; attribution is appreciated. These are illustrative demo images, not Athena client work.

## Functional boundaries

The demo forms, bookings, and checkout interactions run locally in the browser. They do not send leads, make reservations, charge money, or transmit customer information. Prices in the template details are rough planning ranges only; each engagement needs a confirmed scope and quote.
