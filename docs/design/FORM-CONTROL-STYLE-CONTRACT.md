Athena Form Control Style Contract

All interactive HTML controls (select, input, textarea, button, details, summary) must have dedicated scoped CSS in their template, covering default, hover, focus-visible, disabled, selected, and mobile states. Native select must use appearance:none, relative wrapper, non-interactive chevron, minimum 44px touch target and native keyboard behavior. Preserve distinct brand DNA. Verify 320/390/428/1440 viewport, keyboard and reduced motion. Never ship browser-default naked controls.
