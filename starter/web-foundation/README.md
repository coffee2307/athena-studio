## Start
1. Review `src/config/site.ts` and `src/server/modules/manifest.json`.
2. Add project-owned environment values to the hosting provider; `.env.example` contains no credentials.
3. Run `npm install`, then `npm run dev`.
4. Review accessibility, SEO, security, content rights and the selected module checklist before release.

This starter is a separate project. It does not connect to Athena's database, auth, customer records or deployment. Authentication, leads, booking, commerce and content modules are declared as selections only; implement and test each module for the customer's actual requirements before enabling it.
