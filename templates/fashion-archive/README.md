# ATELIER ARCHIVE — FORM IN MOTION / LIGHT STUDY 02

Independent Next.js fashion template with three user-supplied CC BY 4.0 GLB character models, a filterable gallery, detail pages, atelier, About and Contact.

The hero uses one Three.js canvas and GLTFLoader with a local Draco decoder. GLB assets load on selection, are recentered and fitted to the actual viewport, rotate around world Z, and can be switched using three large accessible dots. Rendering pauses offscreen or while hidden. Reduced-motion disables continuous rotation. Unsupported WebGL shows a visible fallback without hiding links or copy.

All Fashion Archive UI uses locally bundled Be Vietnam Pro. Legacy Georgia and Times New Roman are prohibited for Vietnamese. For model authors, original URLs, license and changes, see public/ASSET-SOURCES.md.

Build standalone: npm ci; npm run build; npm start. Fashion Archive models are in public/models. Athena demo copies the same files into public/template-demos/fashion-archive/models. The Contact form drafts email locally only. Illustrative Pexels photos on collection pages are not real inventory. Do not merge/deploy without explicit authorization.
